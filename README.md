# 💰 PaisaTrack

### Smart Personal Finance Manager with AI Advisor

PaisaTrack is a modern personal finance management application designed to help users track their income and expenses, understand spending patterns, manage budgets, and make better financial decisions.

Unlike a basic expense tracker, PaisaTrack combines financial tracking with an **AI Advisor** that provides personalized insights and guidance based on the user's financial activity.

## ✨ Key Features

- 📊 **Financial Dashboard**
  - View income, expenses, and net balance at a glance
  - See recent financial activity

- 💸 **Transaction Management**
  - Add income and expense transactions
  - Categorize transactions
  - Track payment methods and transaction dates

- 🤖 **AI Advisor**
  - Interactive AI-powered financial assistant
  - Ask questions about your spending and budget
  - Get personalized financial guidance and suggestions

- 📈 **Spending Analytics**
  - Visualize spending trends
  - Category-wise expense breakdown
  - Monthly spending insights
  - AI-generated financial insights

- 🎯 **Budget Goals**
  - Create and manage monthly budget goals
  - Track progress toward spending targets
  - Take part in spending challenges

- 🤝 **Split Bills**
  - Split expenses with friends
  - Track amounts others owe you or you owe them
  - Support equal bill splitting

- 📷 **Receipt Scanning**
  - Scan receipts to simplify transaction entry

- 👤 **User Profile**
  - Personalized user profile
  - Financial activity overview
  - Account settings

- 🔐 **Cloud Data Storage**
  - User financial data is stored securely using a cloud database
  - Authentication and user-specific data management

🎯 Problem

Managing personal finances often means manually recording expenses, checking budgets, and trying to understand spending patterns across different transactions.

Traditional expense trackers mainly act as digital ledgers. They store transactions but do not actively help users understand what their financial data means.

💡 Solution

PaisaTrack turns personal finance tracking into an interactive experience.

Users can record their income and expenses, analyze their spending, set budget goals, split bills, and interact with an AI Advisor for personalized financial guidance.

The goal is to move from simply recording financial activity to understanding and improving financial decisions.

🤖 AI Advisor

The AI Advisor is an important part of PaisaTrack.

Instead of functioning only as a generic chatbot, it is designed around the user's financial context and can help answer questions related to:

Spending patterns
Budget management
Expense categories
Saving decisions
General financial planning

This makes the AI useful as a decision-support layer on top of the user's financial tracking data.

🔒 Privacy & Security

PaisaTrack is designed to keep financial information associated with individual user accounts and uses authentication and cloud database services for data management.

📌 Project Status

PaisaTrack is a working project with a deployed web application and an integrated AI Advisor.
