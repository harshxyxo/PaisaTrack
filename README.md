# 💰 Personal Expense Tracker

A smart and intuitive financial dashboard application built to help users seamlessly track their daily income, expenses, and overall budget health.

## ✨ Key Features
- **Dashboard Overview:** Visual representation of monthly spending limits and remaining balances.
- **Transaction Management:** Easily add, edit, or delete daily expense records.
- **Cloud Database:** Securely stores all user financial data in the cloud using MongoDB Atlas, ensuring zero data loss.
- **Clean UI:** Simple, interactive frontend built with fundamental web technologies.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MongoDB Atlas (NoSQL)
- **Version Control:** Git & GitHub
